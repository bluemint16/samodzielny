Asystent marketingu sklepu

Wspólny agent AI naszej społeczności. Instalujesz go raz, nowe umiejętności dostajesz w aktualizacjach.

Czego potrzebujesz

  1. Aplikacji Claude na komputer (Mac albo Windows) i płatnego planu Claude.
  2. Pustego folderu na komputerze, np. Mój sklep.

Instalacja (5 minut)

  1. Otwórz aplikację Claude i przejdź do zakładki Code.
  2. Wybierz folder Mój sklep jako folder pracy.
  3. Skopiuj wiadomość poniżej, wklej ją do Claude i wyślij.
  4. Gdy Claude poprosi o zgodę na uruchomienie polecenia, kliknij zgodę.
  5. Na koniec otwórz nową rozmowę w tym samym folderze i napisz: start.
Zainstaluj mi asystenta marketingu sklepu Luka ze społeczności Samodzielny e-commerce. Tłumacz mi wszystko prostym językiem.
1. Sprawdź, czy działa polecenie: claude --version
2. Jeśli nie działa, zapytaj mnie o zgodę i zainstaluj Claude Code oficjalnym instalatorem Anthropic (Mac: curl -fsSL https://claude.ai/install.sh | bash, Windows w PowerShell: irm https://claude.ai/install.ps1 | iex). Jeśli po instalacji polecenie dalej nie działa, użyj pełnej ścieżki do programu, którą poda instalator.
3. Uruchom: claude plugin marketplace add {{BASE_URL}}/marketplace.json
4. Uruchom: claude plugin install luka@samodzielny
5. Sprawdź: claude plugin list (luka@samodzielny ma mieć status enabled)
Jeśli coś się nie uda, wyjaśnij mi prosto, co się stało, i zaproponuj, co zrobić. Na końcu powiedz mi, żebym otworzył nową rozmowę w tym samym folderze i napisał: co nowego

Po instalacji

Nie musisz pamiętać komend. Pisz zwyczajnie, np. „zróbmy branding”, „sprawdź SEO mojego sklepu”, „co nowego”. Gdy asystent napisze, że jest nowa wersja, odpisz: aktualizuj.

Twoje dane zostają w folderze „Mój sklep” na Twoim komputerze. Aktualizacje zmieniają tylko umiejętności asystenta, nigdy Twoich plików.
