# Mechanizmy Meta: ściąga do analizy

## Efekt podziału (Breakdown Effect)

Błędne przekonanie, że Meta przesuwa budżet do „słabszych” części kampanii. W rzeczywistości system maksymalizuje łączny wynik, optymalizując koszt **następnego** wyniku. Raport z podziałem (na umiejscowienia, wiek, płeć, urządzenia) pokazuje średnie, a system patrzy na następną złotówkę. Część z wysokim średnim kosztem może chronić kampanię przed jeszcze wyższym kosztem gdzie indziej.

Jak rozpoznać: zobacz koszt tej części w czasie. Gdy koszt następnych wyników szybko rośnie, system i tak przesunie budżet. Wysoki średni koszt przy dużych wydatkach zwykle oznacza, że wcześniej w okresie system znalazł tam tanie wyniki.

## Faza uczenia

Okres, w którym system sprawdza, jak wyświetlać nowy albo istotnie zmieniony zestaw reklam. Wyniki mniej stabilne, koszt zwykle wyższy, wyniki nie przewidują przyszłości. Koniec po ok. 50 zdarzeniach optymalizacji w 7 dni od ostatniej istotnej zmiany.

Istotne zmiany, które restartują uczenie: odbiorcy, zdarzenie optymalizacji, duża zmiana reklam, strategia lub wysokość stawki, zmiana budżetu o ponad ok. 20%.

Zasady: nie edytuj w trakcie uczenia, nie rozdrabniaj na wiele zestawów (każdy potrzebuje własnych 50 zdarzeń), budżety realistyczne.

„Ograniczona faza uczenia” = zestaw nie zbiera dość zdarzeń. To problem budowy (za mały budżet, za wąska grupa, za rzadkie zdarzenie), nie słabości reklamy.

## Rankingi trafności reklamy

| Ranking | Poniżej średniej oznacza | Działanie |
|---|---|---|
| Ranking jakości | problem z reklamą | test nowych formatów i haczyków |
| Ranking współczynnika zaangażowania | haczyk nie przyciąga | test nowego otwarcia, pierwszych 3 sekund |
| Ranking współczynnika konwersji | problem po kliknięciu | porównaj stronę docelową z reklamą |

Oceniaj przy ok. 500+ wyświetleniach reklamy.

## Nakładanie się odbiorców w aukcji

Gdy zestawy na tym samym koncie celują w pokrywające się grupy, do aukcji wchodzi tylko jedna Twoja reklama (ta o najwyższej wartości). Pozostałe są wykluczane i nie mogą się uczyć. Objawy: przewlekła ograniczona faza uczenia, niewydany budżet, nierówne wyświetlanie. Rozwiązanie: połączyć zestawy albo wstrzymać słabszy z nakładających się.

## Tempo wydatków (pacing)

System rozkłada wydatki w czasie, żeby trafić na najlepsze okazje. Nierówne dni to norma. Sygnałem jest dopiero niedowydanie przez 3+ dni.

## Zmęczenie reklamy

Skuteczność spada, gdy ci sami ludzie widzą tę samą reklamę wiele razy. Obserwuj częstotliwość (powyżej 3–4 w 7 dni u nowych odbiorców) i spadek konwersji przy stałych wydatkach. Lepiej wymieniać reklamy regularnie niż czekać, aż zmęczenie pokaże się w koszcie.

## Wahania wyników

| Sygnał | Ocena |
|---|---|
| Dzienna zmiana kosztu w granicach 20–30% | norma, pomiń |
| Weekend a dni robocze | norma, uwzględnij |
| Stopniowa zmiana przez tygodnie | trend, zbadaj |
| Nagły wzrost kosztu o 50%+ przez 3+ dni | prawdziwy problem, diagnozuj |
| Wyświetlenia bliskie zera | najpierw konto, płatność, zasady |
| Spadek konwersji przy rosnących wydatkach | zmęczenie reklamy albo problem ze stroną |

## Nazwy wskaźników (jak w polskim Menedżerze reklam)

| W eksporcie (ang.) | Pisz |
|---|---|
| Impressions | Wyświetlenia |
| Reach | Zasięg (konta) |
| Frequency | Częstotliwość |
| Amount spent | Wydana kwota |
| CPM | CPM (koszt 1000 wyświetleń) |
| Clicks (all) | Kliknięcia (wszystkie) |
| CPC (all) | CPC (wszystkie) |
| CTR (all) | CTR (wszystkie) |
| Link clicks / CPC (link click) | Kliknięcia linku / CPC (kliknięcie linku) |
| Outbound CTR | CTR wychodzący |
| Purchases | Zakupy |
| Purchase conversion value | Wartość konwersji z zakupów |
| Cost per purchase | Koszt zakupu |
| Purchase ROAS | ROAS z zakupów (przychód na każdą wydaną złotówkę) |
| ThruPlays | ThruPlay (obejrzenia wideo) |

Polskie nazwy w interfejsie Meta mogą się nieco różnić. Używaj tych, które są w pliku właściciela.
