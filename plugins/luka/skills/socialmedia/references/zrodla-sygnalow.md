# Gdzie szukać sygnałów od klientów

Najpierw źródła własne, potem publiczne. Czytasz tylko strony publiczne: nie logujesz się, nie omijasz blokad, nie kopiujesz treści z prywatnych grup. Każde źródło publiczne otwierasz, zanim je podasz.

## Własne (najmocniejszy dowód)

| Źródło | Jak zdobyć |
|---|---|
| Wiadomości prywatne na Instagramie i Facebooku | właściciel robi zrzuty pytań z ostatnich tygodni (bez danych klientów) i wrzuca do `wyniki/social-media/sygnaly/` |
| Komentarze pod postami i reklamami | zrzuty albo wklejenie tekstu |
| Opinie w sklepie, w Google, na Allegro, Ceneo, Opineo | eksport albo kopiowanie z panelu |
| Pytania przed zakupem (mail, czat w sklepie, telefon) | właściciel wypisuje z pamięci 3–5 najczęstszych, oznaczasz jako „relacja właściciela” |
| Zwroty i reklamacje (powody) | panel sklepu |
| Profil klienta z UVP (`wyniki/uvp/1_*`) | już w projekcie: bóle i zadania klienta są sygnałami, jeśli mają źródło |
| Pytania z SEO (`wyniki/seo/`) | frazy pytające („jak…”, „czy…”, „jaki…”) |

## Publiczne

| Źródło | Co szukać | Uwaga |
|---|---|---|
| Google: wyszukiwanie i sekcja „Podobne pytania” | `[produkt] jak`, `[produkt] czy`, `[problem] co pomaga`, `[produkt] na prezent` | pytania z sekcji podawaj z frazą i datą odczytu |
| Fora tematyczne | np. wizaz.pl (uroda), forum rodziców, forum o zwierzętach, elektroda.pl (elektronika), forum ogrodnicze; wyszukaj `[problem] forum` | data posta zwykle jest przy wypowiedzi |
| Reddit | r/Polska i społeczności tematyczne, `site:reddit.com [problem po polsku]` | |
| Wykop | `site:wykop.pl [problem]` | |
| Opinie u konkurencji | sklepy konkurencji z `wyniki/branding/` i `wyniki/uvp/3_*`: opinie 1–3 gwiazdki (czego klientom brakuje) | świetne źródło problemów, których Twój sklep nie ma |
| Pytania na Allegro i opinie Ceneo | pytania do sprzedającego, opinie produktów z tej kategorii | |
| Komentarze na YouTube i TikToku | recenzje i poradniki z kategorii | często bez dokładnej daty: podaj przybliżoną |
| Grupy na Facebooku | zwykle wymagają logowania: poproś właściciela o zrzuty z grup, do których należy | nie podawaj nazw osób |

## Jak zapisać źródło

- Plik: `wyniki/social-media/sygnaly/zrzut-dm-2026-11-03.png`
- Strona: pełny adres, tytuł wątku, data wypowiedzi
- Relacja właściciela: „relacja właściciela, [DATA rozmowy]”, ocena dowodu najwyżej 2
- Google „Podobne pytania”: „Google, fraza »…«, odczyt [DATA]”
