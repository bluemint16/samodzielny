# Karta decyzji marketingowej

Wypełniasz ją przed napisaniem każdego materiału (post, grafika, wideo, mail, opis). Pilnuje, żeby materiał miał **jedną obietnicę** i opierał się na prawdziwym źródle. Właściciel może poprosić o nią w każdej chwili: „karta decyzji”.

```text
KARTA DECYZJI: [nazwa materiału]
Dla kogo:          [jedna grupa z dane/klienci.md]
Pytanie klienta:   „[dosłownie]” ([źródło], [data])
Jedna obietnica:   [co klient zyska, jednym zdaniem; nic, czego sklep nie dowiezie]
Główna myśl:       [zdanie do zapamiętania]
Dowód:             [fakt ze źródła: cecha produktu, opinia, liczba]
Reakcja:           [ciekawość / zaskoczenie / ulga / obawa / zaufanie / chęć sprawdzenia / chęć rozmowy]
Działanie:         [jedno: pytanie, wiadomość, link, zapis]
Styl:              [nazwa z dane/marka.md, sekcja „Style pisania”]
Czego nie mówimy:  [obietnice bez pokrycia, liczby bez źródła, obniżka bez najniższej ceny z 30 dni]
```

## Bramka

Materiał nie powstaje, gdy:
- obietnic jest więcej niż jedna (wybierz jedną, resztę zostaw na inny materiał),
- obietnica nie ma dowodu,
- nie wiadomo, dla kogo jest materiał,
- działanie na końcu jest więcej niż jedno.

Wtedy powiedz, czego brakuje, i zaproponuj, jak to uzupełnić.
